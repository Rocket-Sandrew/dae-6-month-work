# Six-Month Development Portfolio

This repository contains coursework, programming exercises, cybersecurity projects, technical documentation, and supporting evidence produced during a six-month learning and development programme.

## Repository areas

- `python_1/`, `python_2/`, `logic_1/`, `design_1/`, and `prompt_engineering_1/` contain stages or related exercises associated with the programming and Clue project work.
- `ai_api_integration_1/` contains AI/API coursework and a copy of the web penetration-testing toolkit.
- `Pentesting_Toolkit/` contains the primary Python-based automated web penetration-testing framework.
- `penetration_testing_1/` contains penetration-testing documentation, generated reporting, and supporting evidence.
- `digital_forensics_1/` contains forensic investigation documentation and evidence records.
- `cyber_threats_and_vulnerabilities_2/` contains cybersecurity platform-development work.
- `learning/` contains study notes, planning, tutorials, and interview practice.
- `Markdown_activity/` contains Markdown practice.
- `docs/` contains the source files for the repository's portfolio website.

## Working with the repository

Folders are organized by coursework topic or project stage. Read the README in a folder before running scripts or using its evidence. Some directories contain historical copies, backups, generated reports, or test artifacts; these should not be assumed to be current source files.

## Safety and evidence handling

Only run security-testing tools against systems you own or have explicit permission to test. Treat evidence registers, request/response captures, logs, and reports as project records. Do not publish credentials, API keys, private target details, or sensitive evidence.
