# Portfolio Website Documentation

This directory contains the source content and configuration for the repository's portfolio website.

## Files

- `index.md` provides the home page content.
- `about.md`, `contact.md`, and `projects.md` provide supporting pages.
- `_config.yml` contains site configuration.
- `_START_HERE.md` provides project-specific starting guidance.
- `assets/` contains website assets such as stylesheets.

Edit the Markdown source pages and site configuration rather than generated output. Check the website's build settings before publishing changes.
