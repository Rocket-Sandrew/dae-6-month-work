## Automated Web Penetration Testing Toolkit

![Project 3 image placeholder]({{ '/assets/images/project3.png' | relative_url }})

A Python-based automated web penetration testing toolkit designed to identify and document potential security vulnerabilities in web applications. The framework automates website crawling, endpoint discovery, security header analysis, SQL injection testing, and external redirect detection. It also generates HTML reports containing identified findings, severity levels, supporting evidence, and remediation recommendations.

- **Repository:** [Check my Github](https://github.com/Rocket-Sandrew/dae-6-month-work/tree/main/Pentesting_Toolkit)
- **Live demo:** Not available yet (requires a locally hosted testing environment)
- **What I contributed:** Designed and developed the framework, implemented automated security checks, integrated OWASP ZAP, developed vulnerability detection and validation logic, and created an evidence collection and reporting system with assistance.
- **Tools/technologies:** Python, Visual Studio Code, Requests, BeautifulSoup, APScheduler, OWASP ZAP, Docker, Git, and Juice Shop.
