# Forensic Investigation Process

This directory contains documentation and records for a digital-evidence investigation workflow.

## Contents

- `forensic_investigation_procedure.md` describes the documented procedure.
- `forensic_investigation_report.md` records the investigation report.
- `investigation_log.md` records investigation activity.
- `evidence_register.csv` identifies collected evidence.
- `chain_of_custody.csv` records evidence handling.
- `verification_log.csv` records integrity-verification results.
- `COC-TEST-001_request.txt` and `COC-TEST-001_response.txt` are request/response test artifacts.

Maintain consistent evidence identifiers across the register, custody record, and files. Preserve originals and document any transfer, verification, or authorized disposition.
