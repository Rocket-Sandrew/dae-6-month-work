# Python Coursework — Stage 1

This directory contains early Python coursework and practice scripts.

## Files

- `clue_project.py` contains a version of the Clue-style terminal game.
- `function.py` contains function-focused Python practice.
- `home_destiny_guru.py` contains a separate Python exercise or project.
- `teach_back.py` contains a teach-back exercise.

Run an individual script with Python from this directory, after reviewing its input requirements and behavior. The files represent coursework artifacts and may be separate iterations rather than one combined application.
