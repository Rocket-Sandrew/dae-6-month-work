# AI and API Integration Coursework

This directory contains `clue_project.py` and a copy of the Python-based web penetration-testing toolkit in `Pentesting_Toolkit/`.

The toolkit copy includes reconnaissance, crawling, selected security checks, finding management, evidence handling, HTML reporting, and an OWASP ZAP API integration. See the nested toolkit README for setup and usage details. This directory's name identifies the coursework area; consult the source files to determine the exact AI/API features implemented in each artifact.
